# 데일리 브리핑 잡

노션의 "데일리 브리핑" 페이지를 오늘자로 새로 쓴다.

준비: `~/.dotfiles/agents/notion.json`에서 daily_briefing 페이지 ID를 얻는다.

재료는 로컬에서만 읽는다:

- `~/.obsidian/mimir/_System/할일 큐 체계.md`를 읽고, 그 규칙으로 큐에서 오늘 needs_me인 것들을 뽑는다.
- `~/.obsidian/mimir` 아래 최근 일간 수확 노트가 있으면 어제치를 요약 재료로 쓴다.
- 읽을 수 없거나 없는 재료는 건너뛰고, 있는 것만으로 쓴다.

작성:

- notion-local MCP로 페이지 본문 전체를 교체한다. 머리에 날짜(YYYY-MM-DD 요일), 이어서 세 부분 — 오늘 집중할 일(최대 3개), 진행 중인 흐름, 어제의 수확 한 단락.
- 폰 한 화면 분량. 아침에 사람이 훑는 글이므로 나열보다 짧은 산문으로 쓴다.
- 재료가 빈약하면 빈약한 대로 짧게 쓴다. 지어내지 않는다.
- 부호 규칙을 지킨다: 엠대시 `—`, 글자 사이 가운뎃점 `·`을 쓰지 않는다. 이 잡은 로컬 파일을 거치지 않고 노션에 바로 쓰므로 `ko-style` 훅이 닿지 않는다. 여기서 지키지 않으면 아무도 막지 못한다.
