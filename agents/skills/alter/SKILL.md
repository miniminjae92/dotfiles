# alter

Advisor, Librarian, Tutor, Editor, Roommate 다섯 역할의 머리글자다. 정본은 학습 repo(현재 디렉토리)의 `CURRICULUM.md` 하나이고, 그 상태가 실행할 단계를 정한다. 위에서부터 먼저 맞는 행을 따른다:

| 상태 | 단계 |
|---|---|
| 사용자가 유닛 산출물을 제출함 | Milestone |
| CURRICULUM.md 없음 | Setup |
| 그 외 | Session |

## Setup (최초 1회): Advisor + Librarian

1. 다섯 결정을 인터뷰로 확정한다. 한 번에 한 질문, 결정당 최대 5문항, 이전 답을 근거로 다음 질문을 조준한다.
   - **destination**: 다 배우면 무엇을 할 수 있어야 하는가. 주제("딥러닝")가 아니라 능력("파인튜닝을 돌리고 결과를 평가할 수 있다")으로 받아낸다.
   - **baseline**: 지금 무엇을 알고 무엇을 모르는가. "행렬 곱은 알고 역전파는 모른다" 해상도까지 파고든다.
   - **sequencing**: 유닛을 어떤 순서로 배우는가.
   - **cut list**: 지금은 배우지 않기로 유예하는 것.
   - **milestones**: 유닛마다 통과를 증명할 검증 가능한 산출물. 날짜나 진도가 아니라 물건이다.
2. shelf에 올릴 소스 3~4개를 제안하고 승인받는다. 승인된 소스는 가능한 한 로컬 md로 수확해 경로를 적는다. 수확 도구는 환경에 이미 있는 것을 쓴다.
3. `CURRICULUM.md`를 이 골격으로 쓴다:

   ```markdown
   # CURRICULUM: <주제>
   ## 다섯 결정
   - destination:
   - baseline:
   - sequencing:
   - cut list:
   - milestones: 유닛 표의 산출물
   ## Shelf
   - <소스> (<로컬 경로>)
   ## 유닛
   - [ ] 1. <유닛명> → 산출물: <검증 가능한 물건>
   ## 갭 로그
   - YYYY-MM-DD: <갭>
   ## 판정 기록
   - YYYY-MM-DD 유닛 N: 통과|미달, <근거>
   ## 다음 세션 시작점
   ```

완료 기준: 다섯 결정이 전부 채워졌고, 유닛마다 산출물이 정의됐고, shelf 소스에 로컬 경로가 붙어 있다.

## Session (매 세션): Tutor

1. `다음 세션 시작점`의 유닛을 shelf 소스에 앵커해 진행한다(teach me). shelf에 근거가 없는 주장을 하게 되면 소스부터 보강한다.
2. 세션을 닫기 전 반드시 test me: 한 번에 한 질문으로 사용자가 설명하게 만든다. 설명은 사용자가 하고, 진행자는 질문과 판정만 한다. 사용자가 틀리는 지점이 이 단계의 수확이다.
3. 갭을 갭 로그에 적고 다음 세션 시작점을 갱신한다.

완료 기준: 오늘 날짜의 갭 로그 항목과 갱신된 시작점이 `CURRICULUM.md`에 있다.

## Milestone (주 1회): Editor

1. 제출된 산출물을 적대적으로 리뷰한다: 논리를 공격하고 약점을 찾는다. 판정 질문은 하나다. "이것이 이 유닛을 이해했다는 증거가 되는가."
2. 통과면 유닛 체크박스를 닫고 다음 유닛을 연다. 미달이면 보완 항목을 그 유닛에 삽입한다.
3. 판정과 근거를 날짜와 함께 판정 기록에 남긴다.

완료 기준: 오늘 판정이 판정 기록에 있고, 유닛 목록이 판정과 일치한다.

## Range (선택): Roommate

주 1회, 세션 중 현재 개념을 전혀 다른 분야와 연결하는 질문 하나를 섞는다.

## 이웃 스킬 경계

- 에이전트가 만든 강의로 배우고 싶다는 요청은 `teach`다. teach는 에이전트가 가르치고, alter는 사용자의 독학을 운영한다.
- 방금 세션에서 한 작업의 이해 검증은 `teach-back`이다. alter의 test me는 커리큘럼 유닛이 대상이다.
