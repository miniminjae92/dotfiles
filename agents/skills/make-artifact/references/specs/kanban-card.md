# 칸반 카드

## Purpose

팀이 하나의 작업 결과가 현재 어디까지 왔고, 다음에 무엇이 필요한지 빠르게 파악하게 한다.

## Content

다음 내용을 반드시 포함한다.

- 결과 하나를 나타내는 제목
- 현재 상태
- 예 또는 아니요로 판정할 수 있는 완료 기준

완료되지 않은 카드는 바로 시작할 다음 행동 하나도 포함한다.

다음 내용은 실제로 있을 때만 포함한다.

- 확인된 사실
- 막힌 점
- 문제 해결 기록 링크
- 작업 기록 링크

진행 과정 전체, 개인적인 시행착오, 아직 시작하지 않은 미래 작업은 넣지 않는다.

## Structure

다음 순서로 작성하고, 내용이 없는 선택 항목은 생략한다.

```markdown
# <완료할 결과 하나>

- 상태: <시작 전, 진행 중, 막힘, 완료>
- 완료 기준: <검증 가능한 한 문장>

## 확인한 것

<현재 확인된 사실>

## 다음 행동

<바로 시작할 행동 하나>

## 막힌 점

<진행을 막는 조건과 필요한 도움>

## 근거

- <링크>
```

## Evaluation

- [ ] 카드가 결과 하나만 요구하는가?
- [ ] 제목만 읽어도 무엇을 끝내려는지 알 수 있는가?
- [ ] 완료 여부를 예 또는 아니요로 판정할 수 있는가?
- [ ] 완료되지 않은 카드라면 다음 행동이 하나로 명확한가?
- [ ] 확정형 문장은 현재 확인된 사실만 담고 있는가?
- [ ] 진행 과정 전체나 아직 시작하지 않은 미래 작업을 미리 넣지 않았는가?
- [ ] 이 작업을 별도로 우선순위 지정, 담당, 보류, 검토할 수 있는가?
- [ ] 독립적으로 관리할 필요가 없는 다음 행동을 새 카드로 만들지는 않았는가?
